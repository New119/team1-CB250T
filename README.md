## プロダクトゴール

- 落とし物をした人と拾った人をつなぐ。
- 落とし物の情報を簡単に共有・検索できる環境を提供する。
- 持ち主が落とし物を発見し、手元に戻せる可能性を高める。

↓

**学校全体の生徒・教職員が、落とし物を簡単に探し、持ち主の元へ直ぐ戻せる環境を実現する。**

## 機能（重要性順）

1. 落とし物の登録を出来る
2. 落とし物の一覧表示できる
3. 落とし物の詳細表示
4. 落とし物の検索できる
5. カテゴリー別検索
6. 通知機能
7. 問い合わせ
8. 返却状況管理
9. 本人確認（指定IDの登録）
